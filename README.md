# Small Business Sales & Inventory Centre

A powerful Python and Pandas tool that automates the work of a shop owner 
or business person by cleaning and providing charts and profit analysis of the data. 
It has interactive charts which help in understanding the outputs. 
It also includes profit alerts, low stock warnings and data quality flags.

![Dashboard Screenshot](screen.shot coming soon)

## Tools Used
- Python
- Pandas
- xlsxwriter
- Jupyter Notebook

## How to Run
1. Clone the repository
2. Install required libraries:
   `pip install pandas xlsxwriter openpyxl`
3. Add your own `product.xlsx` and `sales.xlsx` files or use the dummy files provided
4. Run the notebook cell by cell
